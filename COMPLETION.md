## 🚀 Deployment in 3 Schritten:

### **Schritt 1: Repository in Coolify verbinden**
```
Coolify → New Resource → Docker Compose → Repository URL eingeben
```

### **Schritt 2: Environment Variables setzen**
```
STATS_KEY=<openssl rand -hex 24>
KONTAKT_EMPFAENGER=kontakt@mwart.solutions
KONTAKT_ABSENDER=formular@mwart.solutions
```

### **Schritt 3: Deploy starten**
```
https://mwart.solutions ist LIVE mit HTTPS + Reverse-Proxy ✅
```
